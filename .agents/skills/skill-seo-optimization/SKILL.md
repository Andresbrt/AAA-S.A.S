# 🔍 Skill: SEO & Metadata

Garantizar la máxima visibilidad orgánica del proyecto inmobiliario.

## 📌 Reglas Clave:
1. **Next.js Metadata API:** Utiliza `export const metadata: Metadata = {...}` en los layouts y páginas de Server Components para generar títulos, descripciones y etiquetas dinámicas.
2. **Open Graph & Twitter Cards:** Configura las imágenes y descripciones ricas para asegurar que cuando el enlace se comparta en WhatsApp o Redes Sociales, se vea una previsualización de ultra lujo.
3. **Sitemap y Robots:** Genera archivos `sitemap.xml` y `robots.txt` automáticamente (ej. `app/sitemap.ts`) basados en la base de datos de lotes y páginas estáticas.
4. **Datos Estructurados:** Inserta JSON-LD (Schema.org) en las páginas (ej. esquema de 'RealEstateListing' o 'Product' para los lotes).
